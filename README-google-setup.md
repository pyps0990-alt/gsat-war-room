# 連結 Google 帳號（Gmail 寄證書 + Drive 備份）

設定完成後會有兩個效果：

- **兌換獎勵時**，證書直接從你的 Gmail 寄到你的信箱（不用再手動按送出）
- **一鍵備份／還原**，整包資料（打卡紀錄、錯題、圖片）存到你自己的雲端硬碟，換裝置也拿得回來

沒設定也不影響使用 —— app 一切照常，只是寄信會改用「開啟郵件軟體、你按送出」的方式，備份則用手動匯出檔案。

---

## 前置條件

網站要先部署到 Vercel 拿到正式網址（例如 `https://gsat-war-room.vercel.app`）。
Google 只允許從你事先登記的網址發起登入，所以這一步必須先完成。

---

## 步驟

### 1. 建立專案
前往 [Google Cloud Console](https://console.cloud.google.com/)，左上角專案選單 → **新增專案**。
名稱隨意（例如 `gsat-war-room`），建立後確認右上角已切換到這個專案。

### 2. 啟用兩個 API
左側選單 **API 和服務 → 程式庫**，分別搜尋並各按一次「啟用」：

- `Google Drive API`
- `Gmail API`

### 3. 設定 OAuth 同意畫面
左側 **API 和服務 → OAuth 同意畫面**：

| 欄位 | 填法 |
|---|---|
| User Type | **外部（External）** |
| 應用程式名稱 | 學測戰情室 |
| 使用者支援電子郵件 | 你的 Gmail |
| 開發人員聯絡資訊 | 你的 Gmail |

接著在 **測試使用者（Test users）** 按「新增使用者」，把**你自己的 Gmail 加進去**。

> 發布狀態維持在「測試中」就好。這代表只有名單上的帳號能登入 —— 對只有你自己用的 app 來說剛好，也不必送 Google 審查。
> 唯一的限制：測試模式下的授權每 7 天會過期，屆時重新點一次「連結 Google 帳號」即可。

### 4. 建立 OAuth 用戶端 ID
左側 **API 和服務 → 憑證 → 建立憑證 → OAuth 用戶端 ID**：

- 應用程式類型：**網頁應用程式**
- 名稱：隨意
- **已授權的 JavaScript 來源** → 新增這兩筆（**結尾不要加斜線、不要有路徑**）：
  - `https://你的專案名稱.vercel.app`
  - `http://localhost:3000`
- 已授權的重新導向 URI：**留空**（這個 app 用的是 token 模式，不需要）

按建立，複製畫面上那串**用戶端 ID**（結尾是 `.apps.googleusercontent.com`）。

### 5. 填進程式碼
打開 `google.js`，把用戶端 ID 貼到最上面：

```js
const CLIENT_ID = '你的用戶端ID.apps.googleusercontent.com';
```

重新部署後，頁尾就會出現「連結 Google 帳號」按鈕。

---

## 安全性說明

- **用戶端 ID 不是密鑰**，本來就會出現在前端原始碼裡，公開沒有問題。真正的保護是第 4 步的「已授權的 JavaScript 來源」白名單 —— 只有你登記的網址能用這組 ID 發起登入。
- 權限範圍刻意選最窄的兩個：
  - `drive.file`：**只能存取這個 app 自己建立的檔案**，碰不到你雲端硬碟裡的其他任何東西
  - `gmail.send`：**只能寄信，不能讀取**你的任何郵件
- 存取權杖只放在 `sessionStorage`，關掉分頁就消失，不會長期留存。

## 驗證有沒有成功

1. 開啟網站，頁尾按「連結 Google 帳號」→ 完成 Google 授權
2. 按「備份到 Drive」→ 到你的[雲端硬碟](https://drive.google.com)確認出現 `gsat-war-room-backup.json`
3. 兌換一個獎勵 → 在證書上按「寄一份到我的信箱」→ 檢查 Gmail 收件匣
4. 開無痕視窗載入同一網址 → 連結 Google → 按「從 Drive 還原」→ 確認打卡紀錄、錯題與圖片都完整回來
